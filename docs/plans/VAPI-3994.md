## Key Decisions

- `delegation: {type: "responses", responses: {model, tools, tool_choice}}` — tools live in Responses config, not accept Session config (Session TypedDict has no `tools` field)
- Sideband receives `response.event` wrapping Responses API events; handle `response.output_item.done` → function_call `refer`
- `tel:{REFER_TO}` URI in sessions.refer() — Live API supports tel: URIs (Realtime SIP does not)
- `asyncio.create_task()` from async webhook handler — no threading needed
- No `OPENAI_SIGNING_SECRET` in initial version — add later
- No `REFER_SIP_HOST` — not needed with tel: URIs

## Discovered

- `session_accept_params.Session` TypedDict has no `tools` field — tools must go in `delegation.responses.tools`
- `SessionUpdateConfigParam` only allows updating `delegation` — no tools update after startup
- `ConnectServerEvent` union includes `ResponseEvent` — sideband and WebSocket connection share same event types
- Sideband tool call event path: `event.type == "response.event"` → `event.event.get("type") == "response.output_item.done"` → `item.get("type") == "function_call"`
